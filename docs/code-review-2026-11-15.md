# B 站访问与工作台改动评审（2026-11-15）

本次检查覆盖当前批次的访问保护、yt-dlp 传输、平台凭据配置、博主目录同步、字幕身份与持久化、下载导出，以及前端解析、轮询、任务事件和配置入口。所有修复与测试随同代码提交。

## 审查发现与处理

| 问题 | 处理 |
| --- | --- |
| 旧请求可能覆盖显式刷新的新缓存 | 按资源管理在途请求及回写资格；补并发回归 |
| 旧字幕与损坏来源记录缺少完整防护 | 统一读取校验；检查 BV/CID、文本摘要、所选分 P 时长及旧文本时间戳 |
| 非有限、负数或逆序时间轴 | 拒绝使用，给出可恢复错误 |
| 字幕 URL 未限制目标，重复实现身份检查 | 提取共享身份模块，限制 HTTPS 域名、端口及内嵌凭据 |
| 备用 pagelist 分支吞掉字幕正文错误 | 将正文提取移出元数据异常捕获范围 |
| 签名素材缓存被登录验证复用 | 仅签名素材缓存，登录校验实时执行 |
| 配置多进程写入可能丢更新 | 增加文件锁与原子替换；拒绝 Cookie 控制字符 |
| 旧 SSE 任务帧可能污染新视频 | 同时核对页面代次、订阅实例与取消状态；移除重试监听器 |
| 轻量元数据没有下载格式 | 下载页按需请求完整格式，合并同时请求并隔离旧结果 |
| 图片 CDN 429 扩成全局暂停 | 图片单独冷却、缓存与去重；账号 API 限制保留保护 |
| 批量任务同步 HTTP 阻塞事件循环 | 在工作线程执行平台字幕请求 |

## 验收重点

1. 从博主列表连续打开不同视频，确认标题、字幕与返回位置对应。
2. 打开已缓存字幕，确认无需重新联网；点击重新获取后检查任务与来源记录。
3. 切换分 P，确认字幕与时间轴对应；导出 SRT/TXT 并检查内容。
4. 切换下载页，确认按需加载格式及失败提示，返回字幕页仍可读取资料。
5. 进入通用配置，确认 Cookie 不回显，留空保存保留已有配置，验证反馈清楚。
